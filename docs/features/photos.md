# Photos

Status: approved.

A signed-in technician, owner, or admin opens a photo they already see and downloads that file. The three roles see and do the same work. A signed-out request is unauthorized. A person who cannot open the service cannot open or download its photo.

## Which photos

The control applies to every photo an operator added:

- A service photo.
- A part photo.
- A status-change photo.
- A photo chosen on the registration or correction screen that is not saved yet.

## The screen

The thumbnail stays as it is. Clicking it opens that photo large on the same page. The page underneath stays put.

The large view has a download control and a close control. The download control saves that photo to the operator's computer. The file is the photo that was stored, or the file the operator just chose. The close control returns to the screen.

The large view does not edit or delete the photo.
